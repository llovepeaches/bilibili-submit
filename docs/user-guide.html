使用说明

管理你自己账号的视频投稿：扫码登录、单个投稿、批量任务、 历史记录，都在这一个窗口里。左边的目录对应程序的五个页签，遇到问题先看 「常见问题」。

◆开始之前

不需要装 Python ffmpeg 已内置（自动封面用） 数据只存在本机

程序左侧是五个页签，按投稿顺序排：登录 → 投稿 → 批量任务 → 历史 → 设置。 窗口最底下有一条常驻状态栏，随时能看到是否已登录和 ffmpeg 是否就绪， 不用进设置页翻。

所有耗时操作（取二维码、上传）都在后台跑，窗口不会卡住； 登录和投稿都能随时点「取消」。

第一次用？ 先拿一个几十 MB 的小视频，把「登录 → 上传 → 拿到 BV 号」整条跑通， 再批量用。

1登录

  1. 左侧点「登录」，点 获取二维码。
  2. 打开手机 B 站 App，扫窗口里的二维码。
  3. 回到手机上点「确认登录」。 只是在手机上看到二维码、不点确认，程序会一直等到超时（约 180 秒） ——这是最常见的一个坑。

登录成功后，底部状态栏会变成「已登录」。登录状态保存在本机 （见数据在哪），下次打开程序不用重新扫码。

扫完一直卡着？ 看一眼手机——十有八九是没点「确认登录」。二维码过期就点「取消」重新获取。

2投稿

  1. 选视频文件。
  2. 填标题（不超过 80 字）、分区、标签、简介。
  3. 选类型：自制（自己拍的/剪的）或 转载 （转载要填来源地址）。
  4. 拿不准就先点 预览——空跑一遍，只检查不真投。
  5. 点 开始投稿，进度在日志区滚动，完成后给出 BV 号。

封面：留空并用 auto 的话，程序用 ffmpeg 抽视频首帧当封面 ——安装版自带 ffmpeg.exe，开箱即用；也可以直接给一张图片。

条件没齐（没登录、没选文件）时按钮会就地灰掉，旁边写着差什么， 不用点了才知道。跑起来之后主按钮就地变成「取消」。

报错先看日志区。 常见代码的意思都在下面常见问题里，如 601、200009、-352。

3批量任务

选一个文件夹，程序自动扫描里面的视频；顶部填一次共用参数 （分区、标签、简介模板），勾选要投的文件，点开跑。列表里每行有状态着色， 双击可改标题。

简介和标题支持占位符，按文件自动替换：{name} 完整文件名、 {stem} 去掉扩展名、{n} 序号。

分 P 合并

一套视频可以合成一个稿件的 P1/P2/P3（一个 BV 号，播放器里连续切）， 在「分P合并」里选：

模式怎么分
不合并一个文件一个稿件。
按文件名前缀旅行_01 / 旅行_02 合成一套「旅行」； 文件名里没线索时（如 01.mp4）要求序号从 1 开始且连续才敢合并。
按子文件夹每个子文件夹一个稿件，文件夹名当标题——只往下钻一层， 不会一次冒出几百个稿件。
整个目录合并勾选的文件全部合成一个稿件的多 P。
新号务必设任务间隔。 新号、小号的频控明显更严，一口气连投很容易触发风控。 批量任务里把每个任务之间的间隔拉长（分钟级），宁可慢，别封号。

4历史 · 设置

历史

本机投过的稿：BV 号、时间、标题。只记录这台机器上通过本程序投的， 不联网拉取全部稿件。

设置

配代理、换 cookie 路径、切深浅色主题（改完重启生效）， 还有一键环境自检——登录状态、ffmpeg、网络三样逐项打勾。 拿不准环境好不好，先跑一次自检。

🗂数据在哪

登录状态、界面偏好、投稿历史都在用户目录下，不在安装目录：

%USERPROFILE%\.config\bilibili_submit\
├── cookie.json       登录状态
├── ui-state.json     界面偏好（上次用的目录等）
└── history.json      投稿历史

所以卸载不会删掉这些——重装、升级后打开程序，不用重新扫码。 想彻底清干净（换号、送人电脑），把这个 .config 目录一起删掉。

Cookie 等于账号本身。 拿到 cookie.json 就能不扫码直接操作你的账号， 别发给任何人、别上传到网盘或仓库。

？常见问题

现象 / 报错说明与处理
卡在「已扫码，等待确认」 去手机 B 站 App 里点「确认登录」。不点会一直等到超时。
601 投稿过于频繁 频控到了。停一段时间再投；批量任务务必设间隔。
200009 今日投稿次数已达上限 非正式会员单日有数量上限，可在 B 站主站答题转正式会员解除。
-352 风险控制触发 / -412 请求被拦截 操作太像脚本了。停几小时到一两天，降频率、减少单日量再试。
「标题不能超过 80 字」 B 站的硬限制，缩短标题或把信息挪到简介。
「定时时间必须距今 4 小时以上」 预约投稿的时间得设在 4 小时以后。
自动封面不可用 / 找不到 ffmpeg 看底部状态栏的 ffmpeg 一项。安装版自带，若被杀软隔离需还原并加白名单。
杀毒软件报毒 / 文件消失 打包程序常被误判。在 Windows Defender「病毒和威胁防护 → 保护历史记录」 里还原，并把安装目录加入白名单。
上传很慢 / 中途失败 先跑设置里的环境自检；配了代理的话检查代理是否可用； 大文件建议错开网络高峰。

更多排查手段见仓库里的 docs/FAQ.md。
